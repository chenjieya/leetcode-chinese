## 1. 本版功能

本版显式声明 ESLint 9.39.4 开发依赖，解决全新 pnpm 安装后云端检查找不到 eslint 命令的问题。该依赖只参与开发检查，不增加插件安装包体积。1.0.0、1.0.1 保留为源码检查标签，正式安装包使用 1.0.2。

- 基于原 LeetCode 插件建立独立中文衍生版本，插件 ID 为 leetcode-chinese。
- 使用力扣中国站账号、题库、中文题面、运行与提交接口。
- 中文化设置、弹窗、判题、历史提交、竞赛和笔记工作流。
- 支持中文 AI 调试、复盘、模式分类、相关变式与竞赛分析。
- 修复 Alvis 标题格式化兼容问题，题目文件使用“题号. 中文题名.md”。
- 模式、技巧和竞赛目录统一小写，并提供旧目录迁移。

---

补充 pnpm 的定向依赖提升配置，使现有 CodeMirror、Lezer 和 fetcher 间接依赖在全新安装时可被上游代码引用。未引入新库、升级依赖或扩大生产包体积。

## 2. 安装

下载 leetcode-chinese.zip，解压到知识库的 .obsidian/plugins/leetcode-chinese/，确认 main.js、manifest.json 和 styles.css 位于该目录根层级，然后启用 LeetCode Chinese。需要 Obsidian 桌面版 1.12.7 或更新版本。

从原插件迁移时先关闭原插件，再启用本插件。重新登录中国站并配置 AI，题目目录可继续选择原笔记目录。升级本插件时保留 data.json。

本次为 GitHub 发布，社区市场状态以 Obsidian Community 实际审核结果为准。
