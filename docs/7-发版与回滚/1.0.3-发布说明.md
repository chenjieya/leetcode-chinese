Shell Execution 是对实际能力的提示，不应通过隐藏 child_process 引用规避。只有选择 AWS 凭据链并配置 credential_process 才会走外部辅助程序路径；提交的题目代码发送至力扣判题，不在本机执行。

## 3. 安装与重新检查

下载本版 leetcode-chinese.zip，解压到知识库的 .obsidian/plugins/leetcode-chinese/；升级时保留 data.json，随后重新启用插件。

市场提交仍由维护者手动完成。发布后，在已有提交页面选择或刷新 1.0.3 版本并重新运行检查；若页面保存了旧 description，也需改成新版 manifest 中的描述。GitHub Release 成功不代表市场审核已通过。
